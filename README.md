# Gif-maker

A lightweight Python script that programmatically generates a smooth, looping GIF animation using the **Pillow (PIL)** library. The script dynamically renders expanding green circles overlaid on a contrasting red background to create a hypnotic visual effect.

---

## 🚀 Features

* **Dynamic Rendering:** Generates individual frame coordinates dynamically using Python's mathematical operators rather than loading external static images.
* **Modern Pillow Implementation:** Utilizes the up-to-date `.save()` syntax without relying on deprecated parameters.
* **Infinite Looping:** Automatically configured to loop endlessly (`loop=0`).
* **Highly Customizable:** Easily adjust frame rates, dimensions, colors, and step frequencies directly inside the variables.
